Privacy Policy

Last updated: August 2026

VaultMind ("the project," "we") is an independent, single-operator automated video pipeline. It publishes pre-generated videos to its own YouTube and TikTok accounts. This policy explains what data the pipeline touches when it connects to those platforms, and what this site collects from visitors.

What this covers

This policy applies to (a) this website, and (b) the TikTok and YouTube API connections used by the VaultMind publishing pipeline. It does not apply to YouTube, TikTok, or any other third-party platform itself — their own privacy policies govern how they handle your data.

Data the pipeline accesses

When the operator authorizes VaultMind's TikTok app via OAuth, the pipeline receives:

  • Basic public profile info for the connected account (username, display name, avatar) — used only to confirm which account a video is about to be posted to.
  • Permission to publish video posts to that same account via TikTok's Content Posting API.

The pipeline does not read direct messages, contacts, analytics, or any other TikTok data, and does not access any TikTok account other than the one the operator explicitly connects.

What we don't collect

This site does not use cookies, analytics scripts, or advertising trackers, and does not have a login, comment system, or form that collects visitor information. Standard web server access logs may be kept temporarily by our hosting provider (GitHub Pages) as part of their own infrastructure — see GitHub's privacy statement.

How authorization data is stored

The OAuth refresh token used to publish videos is stored as an encrypted secret in the pipeline's GitHub Actions configuration. It is never logged, displayed, committed to source control, or shared with any third party. It is used solely to obtain short-lived access tokens for publishing to the connected account.

Data retention & revocation

Authorization data is kept only as long as the pipeline remains active. The account holder can revoke VaultMind's access at any time from TikTok's app-permissions settings (Profile → Settings → Security → Manage apps) or the equivalent YouTube/Google account permissions page, which immediately invalidates the pipeline's ability to post.

Third-party services

Generating a video involves calling third-party APIs (for script generation, text-to-speech, stock footage, and music) in addition to YouTube's and TikTok's publishing APIs. These calls process the video's generated content, not personal data about site visitors.

Children's privacy

This site and the VaultMind pipeline are not directed at children and do not knowingly collect data from anyone under the age required by TikTok's and YouTube's own terms.

Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly.
